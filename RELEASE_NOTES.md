# v1.0.14

- Added German and English translations. English is used for other client languages.
- Action bars and built-in click-casting bindings are backed up automatically per character, regardless of class, specialization, role, talents, or level.
- The first login saves your current setup. Later logins restore it, and changes are saved as you make them.
- Restoration waits if you are in combat, using a special action bar, or holding something on the cursor. Existing backups are preserved if the game rejects a change. Use `/fbui restore` to retry manually.
