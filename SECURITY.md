# Sicherheitsmeldungen

Bitte mögliche Sicherheitslücken vertraulich über **Security → Report a vulnerability** in diesem Repository melden. Keine Zugangsdaten, privaten SavedVariables oder vollständigen Kontodaten in öffentlichen Issues veröffentlichen.

Für die Prüfung bitte Addon-Version, Zielclient und nachvollziehbare Schritte mit bereinigten Fehlermeldungen angeben. Unterstützt wird der jeweils aktuelle Release.

Die automatischen Prüfungen kontrollieren Lua-Syntax, vorhandene Funktionstests und bekannte Geheimnismuster. Sie ersetzen keine Spieltests oder unabhängige Sicherheitsprüfung.
