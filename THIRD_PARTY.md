# Herkunftshinweise

Das Addon verwendet Blizzards native UI-Texturen und Vorlagen direkt aus dem Spielclient.

Expressway ist eine Schrift von Typodermic Fonts. Das Addon unterstützt eine für den Einsatz im Spiel lizenzierte lokale Datei. [Lizenzinformationen von Typodermic](https://typodermicfonts.com/license/).
