# Projektbilder

- `icon-400.png`: quadratisches Projekticon (400 × 400), für die spätere CurseForge-Projektseite.
- `github-social-preview.png`: GitHub Social Preview (1280 × 640, unter 1 MB).
- `icon-source.png`: hochauflösende Vorlage.

## GitHub und WowUp

Unter **Settings → General → Social preview → Edit → Upload an image** die Datei `github-social-preview.png` auswählen. Ein Bild im Repository oder im README setzt diese Einstellung nicht automatisch.

WowUp Hub verwendet das Social-Preview-Bild, ersatzweise den Besitzer-Avatar. Nach öffentlicher Freigabe kann das Bild über die oben genannte GitHub-Einstellung hochgeladen werden. Die tatsächliche Anzeige im WowUp-Client anschließend prüfen.

CurseForge: Beim späteren Anlegen des Projekts `icon-400.png` als Projektavatar wählen. Eine Projekt-ID erst nach Erstellung in der TOC ergänzen.

Quellen: [WowUp Hub](https://wowup.io/guide/wowup/hub), [GitHub Social Preview](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

## Gestaltung

Mit dem integrierten Bildgenerator auf Grundlage des vorhandenen eigenen Buddy-Kompasses erstellt. Vorgabe: klarer vierzackiger Kompass, dunkler Hintergrund, gut als kleines Icon erkennbar; Retail in Gold/Türkis, Forever in Silber/Elfenbein mit Bernsteinmitte; UI-Varianten mit UI-Plakette. Exportgrößen technisch angepasst. Die Bilder dienen den Projektseiten und werden nicht ins Installationspaket aufgenommen.
